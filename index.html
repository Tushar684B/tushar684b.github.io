Open-source Tool

Python tool to extract farm field boundaries across all Indian states using the Fields of the World (FTW) dataset. Queries per-tile GeoParquet files from S3 via DuckDB, clips to named region bounding boxes, and exports GeoJSON/Shapefile for 15+ Indian states including Punjab, Karnataka, Maharashtra, and more.
